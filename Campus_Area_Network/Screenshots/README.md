# Project Screenshots

This folder contains screenshots showing the configuration, security, and testing of the Campus Area Network (CAN) project in Cisco Packet Tracer.

## Screenshots Included

### 1. Network Topology

Shows the complete university Campus Area Network topology, including:

* Core Layer
* Distribution Layer
* Access Layer
* University buildings
* Server room
* Network devices and connections

### 2. VLAN Configuration

Shows the VLAN configuration used to separate different types of network traffic.

Configured VLANs include:

* VLAN 10 – IP Cameras
* VLAN 20 – IP Phones
* VLAN 30 – Internet
* VLAN 100 – Servers

### 3. Security Configuration

Shows the security configuration applied to Cisco network devices, including password protection and device access security.

### 4. Console Access

Shows console access configuration used for local management and initial configuration of Cisco network devices.

### 5. Remote / SSH Access

Shows remote access to a network switch from another device/server using SSH for centralized network management.

### 6. Access Testing

Shows testing performed to verify that the configured network access and connectivity are working correctly.

## Purpose

These screenshots provide visual evidence of the network design, VLAN configuration, security configuration, device management, and testing performed in the Campus Area Network project.
